# 📊 Reports Module - Quick Reference Card

## 🎯 What is Reports?

A powerful analytics tool to create, manage, and export custom sales reports with advanced filtering, grouping, and visualization.

---

## 📋 Report Types at a Glance

| Type | Use Case | Best For |
|------|----------|----------|
| 📊 **Sales Summary** | Overall metrics | Monthly overviews |
| 📦 **Item-wise** | Product performance | Top sellers |
| 👥 **Customer-wise** | Customer analysis | VIP identification |
| 📈 **Date-wise** | Trend analysis | Forecasting |
| 🎯 **Lead Conversion** | Pipeline metrics | Sales effectiveness |
| 📌 **Quotation Status** | Deal tracking | Pipeline monitoring |

---

## ⚡ Quick Start (2 minutes)

### Create a Report
```
1. Click: Reports → Add Reports
2. Name: "My First Report"
3. Type: Sales Summary
4. Click: Preview Report
5. Click: Create Report ✓
```

### View & Download
```
1. Click: Reports → View Reports
2. Find your report
3. Click: 📥 CSV to download
4. Open in Excel
```

## 🎨 Features Quick Lookup

| Feature | How to Use | Benefits |
|---------|-----------|----------|
| **Filters** | Specify dates, customer, item, status | Narrow down data |
| **Grouping** | Select "Group By" option | Organize data |
| **Field Selection** | Check/uncheck fields | Custom columns |
| **Graphs** | Toggle "Include Graphs" | Visual insights |
| **Preview** | Click "Preview Report" | See before saving |

| **Templates** | Click "⭐ Template" | Reuse settings |

## 👥 Group By Options

| GroupBy | Groups data by | Use when |
|---------|---|---|
| Customer | Each customer | Who spends most? |
| Item | Each product | Which sells best? |
| Date | Each day/period | Seeing trends |
| Status | Order status | Tracking progress |
| (None) | Whole dataset | Overall metrics |

## 📊 Available Data Fields

### Sales Summary
- metric, value, orderCount, totalQuantity, averageOrderValue

### Item-wise
- item, totalQuantity, totalSales, orderCount, averagePrice

### Customer-wise
- customer, email, phone, totalSpent, orderCount, totalQuantity

### Date-wise
- date, totalSales, orderCount, totalQuantity

### Lead Conversion
- totalLeads, convertedLeads, conversionRate, pendingLeads

### Quotation Status
- status, count, totalValue

- ✓ Try again from preview

- ✓ Check View Reports section
