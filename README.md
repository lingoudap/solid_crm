# 🚀 Solid CRM Application

## 📌 Overview

A full-stack **CRM (Customer Relationship Management)** system built using the **MERN stack**.
This application helps manage leads, customers, quotations, invoices, and follow-ups efficiently.

---

## 🛠️ Tech Stack

* Frontend: React.js
* Backend: Node.js + Express.js
* Database: MongoDB
* Styling: CSS / Tailwind (if used)

---

## ✨ Features

* 👥 Customer Management
* 📊 Lead Management
* 💰 Quotation System
* 🧾 Invoice Management
* 📦 Order Management
* 📅 Follow-up Tracking
* 🖨️ Custom Print Templates
* 📱 Responsive UI

---

## 📂 Project Structure

/client → React frontend
/server → Node backend

---

## ⚙️ Installation

### 1. Clone the repository

git clone https://github.com/lingoudap/solid_crm.git

### 2. Install dependencies

cd client
npm install

cd ../server
npm install

### 3. Run the application

# Backend

cd server
npm start

# Frontend

cd client
npm start

---

## 🔐 Environment Variables

Create a `.env` file in server:

PORT=5000
MONGO_URI=your_mongodb_connection
